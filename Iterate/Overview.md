# Overview

1. This is a specification for files with extension '.nyo'
2. **Nyo Files** may contain only a subset of ASCII: newline, space, capital and lowercase letters, digits, and the following 32 special characters: { } [ ] ( ) \ / ' ` " ~ < > ? ! @ # $ % ^ & * _ - + = | : ; , .
3. **Nyo Files** always contain an even number (possibly zero) of the double-quote character "
4. **Regular Text** refers to any part of a **Nyo File** which is before the first double-quote, after the last double-quote, or between an even-numbered double-quote and the next double-quote in the file. Excludes the double-quotes themselves.
5. **Quoted Text** refers to any part of a **Nyo File** which is between an odd-numbered double-quote and the next double-quote in the file. Excludes the double-quotes themselves. All characters allowed in **Nyo Files** except the double quote itself may appear inside **Quoted Text**.
6. The backslash character can only appear inside **Quoted Text**. When it appears, it must either be followed by N, T, S, or Q. These pairs of characters starting with a backslash are called **Escaped Newlines**, **Escaped Tabs**, **Escaped Backslashes**, and **Escaped Doublequotes**.
7. Each **Nyo File** is composed of one or more **Statements** separated by **Statement Separators**. A **Statement Separator** is defined as any semicolon or newline in **Regular Text**. A **Statement** is defined as either all characters before the first **Statement Separator**, all characters after the last **Statement Separator**, or the characters between one **Statement Separator** and the next. **Statements** exclude the **Statement Separators** themselves. **Statements** can be empty, such as the **Statement** between two consecutive newlines. **Quoted Text** contains no **Statement Separators** by definition. A **Nyo File** containing zero **Statement Separators** is interpreted as a file with one **Statement**, which may be the empty **Statement**.
8. Each **Statement** is composed of zero or more **Items** which may be separated by **Item Separators**. **Quoted Text** including its initial and final double-quotes is always one **Item**. A single space or any number of consecutive spaces create a single **Item Separator**. Some consecutive **Items** do not require **Item Separators** and will therefore not have spaces between them, but each space in **Regular Text** is part of an **Item Separator**. **Statement Separators** are neither **Items** nor **Item Separators** by definition, since they exist outside **Statements**. There is no such thing as an empty **Item**. Leading and trailing **Item Separators** in a **Statement** are ignored.
9. The special characters ' and ` can only appear inside **Quoted Text**.
10. **Items** in **Regular Text** may contain only capital and lowercase letters, digits, and the following 27 special characters: { } [ ] ( ) / ~ < > ? ! @ # $ % ^ & * _ - + = | : , .
    - The characters { } [ ] ( ) always form single-character **Items**. **Statements** containing these **Grouping Items** always contain an even number of them arranged in such a way that each **Group** opened is always subsequently closed, and any **Group** opened inside another **Group** is always closed before that other **Group** closes.
    - The & and | characters always form single-character **Items**. These **Items** are the **AND Operator** and **OR Operator**. Note that Nyo does not use the conventional two-character versions of these operators which appear in other languages.
    - The _ character can appear in two ways: on its own as **Null** or as part of a **Name**.
11. Outside of **Quoted Text**, letters and digits exist only in three types of **Items**: **Names**, **Keywords**, and **Numbers**.
    - **Names** begin with a letter and are followed by any uninterrupted series of letters, digits, and underscores. A **Name** ends when any other character or the end of the file appears. A **Name** cannot end with an underscore.
    - **Keywords** contain only letters and have special effects defined by the Nyo specification in advance.
    - **Numbers** are composed of an optional negative sign, followed by one or more digits and at most one decimal point. The decimal point is always after a digit and is never the last character in the **Number**. The first digit in a **Number** can only be zero if that zero is immediately followed by a decimal or if the **Number** is the zero character on its own. A **Number** ends when any non-digit character (except a correctly placed decimal or leading negative sign) or the end of the file appears.
12. The end of a **Nyo File** terminates any **Items** or **Statements**.
13. A **Nyo File** which does not or cannot meet this full specification is invalid in its entirety.
